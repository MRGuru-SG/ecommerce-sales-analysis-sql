# E-Commerce Sales Analysis Using SQL

## Project Overview
Analyzed a sample e-commerce dataset containing 5,000 records using MySQL to identify sales trends, profitability, top products, and customer insights.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Dataset
- Total Records: 5,000
- Format: CSV
- Type: Synthetic practice dataset

## Key Performance Indicators (KPIs)
- **Total Sales:** 14,225,390.10
- **Total Profit:** 9,784,107.36
- **Average Sales per Record:** 2,845.08

*Note: This is synthetic practice data and does not represent a real company.*

## Analysis Performed
- Category-wise sales and profit analysis
- Top-performing products
- State-wise sales performance
- Monthly sales trends and growth
- Order status and sales channel analysis
- Customer segment analysis
- Product ranking
- Profit margin analysis

## SQL Concepts Practiced
- SELECT, WHERE, ORDER BY
- GROUP BY and aggregate functions
- JOINs
- Subqueries and CTEs
- Window functions: DENSE_RANK() and LAG()
- Data quality checks
- KPI calculations

## Project Files
- `ecommerce_sales_project.sql` — SQL queries and analysis
- `ecommerce_sales_5000.csv` — Sample dataset
- `README_ecommerce_sql_project.txt` — Project notes

## Key Learnings
Practiced SQL data analysis, data validation, KPI calculations, ranking, and trend analysis.
